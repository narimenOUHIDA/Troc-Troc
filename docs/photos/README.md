# Photos

Dépose ici les photos brutes ajoutées à la main via GitHub (bouton **Add file → Upload files**, pas *Create new file* qui ne permet pas de joindre une image).

Une fois une photo ici, elle doit être déplacée vers `frontend/src/lib/assets/` (et importée dans `frontend/src/lib/annonces.js`) pour être réellement utilisée sur le site — ce dossier n'est qu'une zone de dépôt, pas l'endroit que l'application va lire.
